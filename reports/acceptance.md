## Remaining blockers (platform-owned)

1. **Hosted structure input:** `curated_serving` supports only `stored_image` (JPEG/PNG) file inputs. P2Rank needs PDB/mmCIF files, or a string input of at least 2 MiB.
2. **Files storage:** uploads with content type `chemical/x-cif` and `chemical/x-pdb` are rejected (upstream HTTP 400 from the external Files service allowlist). This blocks user-supplied structures through platform uploads, in managed runs as well as hosting. A Lab-side workaround (a zipped or `.txt` structure upload, both of which the allowlist accepts) is possible in a 0.1.1 release but is not implemented or verified.
3. **Agent-gateway artifact links** pass HTML through Cloudflare analytics injection (the same issue as item 02). Public API downloads are unaffected.
4. After the platform fixes, production deployment needs fresh explicit approval under AGENTS.md. Then: an exact hosting approval, cold and subsequent hosted invocations with real uploads, and verified limits, cancellation, isolation and idle behavior.
